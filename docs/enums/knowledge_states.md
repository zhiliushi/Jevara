# Knowledge workflow states

Category key: `knowledge_state`

| Key | Label | Purpose |
|---|---|---|
| `inbox` | Inbox | Captured but not yet reviewed |
| `reviewing` | Reviewing | Being read or processed manually |
| `understood` | Understood | Reviewed enough to be useful |
| `in_use` | In use | Actively applied to a project or decision |
| `archived` | Archived | Retained but not currently active |

This is a lightweight review state, not an indicator of objective truth or mastery. Records can remain linked to projects regardless of state.
