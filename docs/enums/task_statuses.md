# Task statuses

Category key: `task_status`

| Key | Label | Purpose |
|---|---|---|
| `todo` | To do | Not started |
| `in_progress` | In progress | Work has started |
| `blocked` | Blocked | Cannot proceed without resolving a dependency |
| `done` | Done | Completed |
| `cancelled` | Cancelled | No longer intended |

A task status is separate from knowledge workflow state and project status.
