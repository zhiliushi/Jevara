# Record origins

Category key: `record_origin`

| Key | Label | Purpose |
|---|---|---|
| `obsidian_sync` | Obsidian sync | Parsed from a vault file |
| `manual` | Manual | Created or edited directly by the user in the app |
| `rule` | Rule-based | Produced by deterministic parsing or NLP |
| `ai` | AI | Proposed by an AI operation |
| `import` | Import | Imported from another source or export |

Origin is provenance, not review status. An AI-origin record can be pending, approved, or rejected.
