# Project statuses

Category key: `project_status`

| Key | Label | Purpose |
|---|---|---|
| `idea` | Idea | Potential project not yet committed |
| `planned` | Planned | Intention and next steps recorded |
| `active` | Active | Work is underway |
| `paused` | Paused | Temporarily not being worked on |
| `completed` | Completed | Objective achieved or project closed |
| `cancelled` | Cancelled | Project intentionally stopped |
