# Note types

Category key: `note_type`

| Key | Label | Purpose |
|---|---|---|
| `knowledge` | Knowledge | A learning note or explanation |
| `source` | Source | A reference to an external source or document |
| `reflection` | Reflection | Personal interpretation, insight, or lesson |
| `question` | Question | An unresolved question to investigate |
| `meeting_note` | Meeting note | Notes from a conversation or meeting |
| `decision` | Decision | A recorded decision and rationale |
| `journal` | Journal | A dated personal log or work log |

Values can be added or deactivated in the database. A note's type is not the same as its workflow state.
