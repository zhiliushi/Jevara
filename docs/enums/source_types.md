# Source types

Category key: `source_type`

| Key | Label | Purpose |
|---|---|---|
| `web_article` | Web article | Online article or blog post |
| `documentation` | Documentation | Product or technical documentation |
| `repository` | Repository | Code repository or project page |
| `video` | Video | Video or recorded talk |
| `paper` | Paper / research | Academic or technical paper |
| `book` | Book | Book or book chapter |
| `conversation` | Conversation | Information from a person or discussion |
| `file` | File | Imported local document |
| `manual_note` | Manual note | Content entered directly by the user |
